这里记录甘露解析各版本的更新内容。想看某一版的完整说明，点导航栏「下载」进各发布页即可。

## v1.0.0（2026-11-28，首次发布）

1. **网盘分享解析**：粘贴链接或整段分享文案（短链、口令均可），自动识别夸克 / UC / 迅雷 / 139 / 123云盘 / 115 / 光鸭 / 蓝奏云（含优享版），一键解析直链下载
2. **视频链接解析**：哔哩哔哩 / 小红书 / 抖音 / 微博 / 快手 / AcFun / Pixiv，短链、口令、整段文案均可识别
3. **高速下载**：多线程分片并发 + 断点续传 + 慢连接自动换线；B 站高清资源两轨并行下载后自动合轨
4. **P2P 下载**：磁力 / BT 种子 / ed2k 链接交给内置 Gopeed 引擎，支持本地种子文件、Tracker 服务器管理与 DHT 开关
5. **在线预览**：直链直接播放、边下边播；未装 FFmpeg 时回退内置播放器，可一键转为下载
6. **Live 图保存**：微博 / 抖音动图可存为动态照片、静态图片或视频
7. **多账号与备份**：网盘与视频平台均支持多账号（主账号 / 备注），认证信息可加密导出 / 导入，换设备不丢号
8. **公告中心**：版本更新、功能上新与重要提醒经顶栏公告入口推送，置顶公告启动时弹窗提醒；支持分平台发布（手机 / 电脑端各看各的）
9. **引擎管理**：FFmpeg（预览 / 合轨）与 Gopeed 内核集中下载 · 更新 · 卸载，装到应用私有目录，不改系统环境变量
10. **凭证本地化**：Cookie / Token 加密落库，仅存本机

双端支持：Windows（含 Win7 兼容版）/ Android。
