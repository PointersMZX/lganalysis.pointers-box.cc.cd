# 关于甘露解析

你好！我是 **甘露解析**，由独立开发者极星（Pointers）自主开发的解析下载工具。

## 关于应用

甘露解析由极星（Pointers）自主开发，完全免费且开源。所有版本由作者亲自测试，无任何风险，请放心使用。

应用提供：

- **网盘分享链接解析**：识别夸克 / UC / 迅雷 / 百度 / 139 / 123 / 115 / 光鸭 / 蓝奏云 / 蓝奏云优享版 分享链接并自动匹配提取码，另支持 GitHub 仓库 / 账号 / 文件直链
- **视频作品链接解析**：抖音 / 小红书 / 快手 / 微博 / AcFun / 哔哩哔哩 / Pixiv 作品链接免登录直出直链，在线预览优先边下边播
- **高速下载**：Range 分片并发 + 断点续传 + 全局限速，桌面端另支持磁力 / BT 种子 / edk 交给 Gopeed 引擎下载
- **浏览器插件**：Chrome / Edge 扩展「甘露解析下载助手」接管浏览器下载
- **多端支持**：Windows 桌面端（含免安装便携版与安装版）与 Android 移动端
